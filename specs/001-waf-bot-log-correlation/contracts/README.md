# Contracts

**Feature**: `001-waf-bot-log-correlation`

This directory describes the interfaces the system exposes. It is *design documentation*; the
executable contract lives in the repository:

| Contract | Authored in | Generated artifact | Consumed by |
|----------|-------------|--------------------|-------------|
| Frontend-facing API | `backend/api/protos/siem/v1/*.proto` (with `google.api.http` annotations) | `backend/api/openapi.yaml` (OpenAPI v3) | Vue SPA, via a TypeScript client generated by `openapi-typescript` |
| Vendor ingest endpoints | `backend/api/protos/siem/ingest/v1/*.proto` + adapter specs | same `openapi.yaml`, `/ingest/v1` paths | Cloudflare Logpush, F5 remote logging, DataDome log export |
| Common event model | `backend/api/protos/siem/v1/common.proto` | Go types + OpenAPI schemas | every service in the pipeline |

**Generation and drift enforcement**

```
make api          # regenerates backend/api/gen/** and backend/api/openapi.yaml
make api-check    # regenerates into a temp dir and fails if the committed output differs
```

`make api-check` runs in CI. A handler change that is not reflected in the contract fails the
build — this is the mechanism behind Constitution Principle I.

**Documents**

- [api-surface.md](./api-surface.md) — the operations the frontend calls, with the invariants every
  one of them must honor
- [ingest-contracts.md](./ingest-contracts.md) — what each vendor sends, how it is authenticated,
  and the acknowledgement and back-pressure semantics
- [events-common-model.md](./events-common-model.md) — the vendor → common model field mapping that
  makes correlation possible

**Versioning**: paths are prefixed `/api/v1` and `/ingest/v1`. Breaking changes ship a new major
prefix and the previous one stays served for at least one release cycle. `buf breaking` runs in CI
against the previous tag to catch accidental breakage.
